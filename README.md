# ExamPYQ Pro — SSC Exam Preparation Portal

A multi-exam SSC preparation portal built with React, TypeScript, Tailwind CSS, and Vite.

## Features

- **Sidebar-Driven Portal Workspace**: Navigate across **Exam Hub**, **Question Bank**, **Mock Test Center**, **Revision Queue**, and **Performance Analytics**.
- **Multi-SSC Exam Tracks**: Switch between **SSC CGL**, **SSC CPO**, **SSC CHSL**, and official **2024 / 2023 Shift Archives** with exam-specific marking schemes (`+2.0/-0.5` and `+1.0/-0.25`).
- **2,000+ Official PYQs Across 4 Core Subjects**:
  - English Language & Comprehension (500 Qs)
  - Quantitative Aptitude (500 Qs)
  - General Intelligence & Reasoning (500 Qs)
  - General Knowledge & General Awareness (500 Qs)
- **TCS-Style CBT Mock Simulator**: Launch full-length or sectional timed tests with question palette navigation, mark-for-review, negative marking calculation, and detailed post-test solution review.
- **Paginated & Virtualized Practice**: Supports both paginated reading and `react-window` virtualized fast scrolling, plus persistent bookmarks, mistake tracking, and JSON export.
